# 정정 쌍 (제가 낸 것 → 마스터가 고친 것)

## 2026-09-10 스피드체크 세션
| 제가 낸 것 | 마스터 정정 | 반영 |
|---|---|---|
| 오타 시 입력이 남고 ⌫ 백스페이스로 지워야 진행 | "한번 틀리면 리셋되서 그냥 맞게 누르면 맞는 걸로, 틀리면 바로 다시 치게" — 초보는 백스페이스 위치도 헤맨다 | `commitInput` 오타 = 입력 버리고 집계만(`revertToCorrect`) |
| 마지막 글자 완성 즉시 다음 아이템으로 전환 | "글자가 써지는 것까지 나오고 나서 넘어가야지, 뭘 잘 쳤는지 보이지도 않는다" | `ITEM_HOLD_MS=650` 보여주기, 키 입력 시 즉시 진행, 보여주기 시간은 속도 제외 |

### 실측으로 반증된 가설
- 천지인 "코 ← 노" 오타는 다음 자음 탭(ㄱㅋ)에서 잡힐 것이라 가정했으나, 실측(`tapKey` 프로브)은 ㄱ이 받침으로 붙어 "녹→놐"이 되고 **다음 모음(ㆍ+ㅡ)이 받침을 옮기는 순간**에야 "노"가 확정돼 오타가 드러났다. 판정 유예 로직은 "확정 시점 = 받침 이동" 기준으로 테스트를 써야 한다.
